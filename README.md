# ReparatieCRM Printhelper

De ReparatieCRM Printhelper drukt bonnen, documenten en labels uit [ReparatieCRM](https://reparatiecrm.nl) rechtstreeks af op de printers van je computer, zonder printdialoog.

Deze repo bevat alleen de installers en updates. Je hoeft hier niets te doen: je downloadt de Printhelper in ReparatieCRM onder **Deze werkplek**, en de Printhelper werkt zichzelf bij.

## Downloaden

- **Windows:** [ReparatieCRM-Printhelper-Setup.exe](https://github.com/maguati/reparatiecrm-printhelper/releases/latest/download/ReparatieCRM-Printhelper-Setup.exe)
- **Mac:** [ReparatieCRM-Printhelper.dmg](https://github.com/maguati/reparatiecrm-printhelper/releases/latest/download/ReparatieCRM-Printhelper.dmg)

Na het installeren kies je in ReparatieCRM bij **Deze werkplek** voor **Koppelen met de Printhelper**.

Windows kan bij het installeren "Onbekende uitgever" tonen; kies dan **Meer info** en **Toch uitvoeren**. Op een Mac open je de app de eerste keer met rechtsklik en **Openen**.
